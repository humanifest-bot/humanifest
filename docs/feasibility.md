# Feasibility

Humanifest is feasible only if it remains small and consent-driven.

Positive signals:

- Candidate projects publish open repositories and contribution pathways.
- GitHub metadata, issues, PRs, docs, and source browsing support Tier 0 and Tier 1 audits.
- Some issue-level opportunities can be scored and parked without consuming maintainer time.

Negative signals:

- Current impact evidence is often self-reported reach, not measured outcomes.
- Many issues are stale, already assigned, already under PR, or design-heavy.
- External environment setup can become the work unless tightly gated.

First-run conclusion: the MVP is useful as a brake and audit trail. It is not yet proof that Humanifest can reliably produce accepted upstream contributions.
