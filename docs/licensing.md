# Licensing Options

No final license choice has been applied in this first run. The repository owner should approve the license before accepting outside contributions.

Recommended split:

- Humanifest source code: Apache-2.0 or MIT. Apache-2.0 gives an explicit patent grant and is a common default for public-interest infrastructure.
- Schemas and protocol documents: CC-BY-4.0 or Apache-2.0. Use Apache-2.0 if the line between spec and code should stay simple.
- Curated project and opportunity data: CC-BY-4.0 for attribution, or CC0 if maximum reuse matters more than attribution.

Avoid incompatible inbound terms. If a target project requires a CLA or DCO, record that in the project record before work advances.

Humanifest currently recommends DCO signoff for its own code contributions unless a legal review chooses a CLA.
