# Governance

Humanifest needs governance before scale.

Required policies:

- transparent scoring and appeals;
- conflict-of-interest disclosure for project selection;
- maintainer opt-in or explicit issue-level confirmation for nontrivial work;
- moderation for harmful, extractive, or promotional behavior;
- public correction process for inaccurate records;
- periodic anti-Goodhart audits.

Kill criteria:

- maintainers report net negative time impact;
- Humanifest-originated submissions are repeatedly closed as spam or low-quality;
- rankings concentrate in already-popular repos while neglected maintainer-requested work is ignored;
- AI provenance or licensing cannot be audited;
- internal activity metrics rise while accepted, retained upstream value does not.
